# Hosbank

Application bancaire Express avec vues EJS, MySQL et une architecture contrôleurs / services / repositories.

## Démarrage

1. Copier `.env.example` vers `.env` et renseigner la base MySQL.
2. Installer les dépendances avec `npm install`.
3. Lancer le serveur avec `npm run dev` ou `npm start`.

L'application est disponible sur `http://localhost:3000`.
